## Tech Stack

- React 19
- Vite 7
- React Router 7
- Tailwind CSS 4
- Framer Motion
- Swiper
- Zustand
- React Hook Form
- Lucide React

## Features

- Car search and filters
- Car details and pricing
- Date-range booking
- Checkout flow
- Coupon support
- Login / Signup
- Booking confirmation
- FAQ section
- Responsive design
- LocalStorage-based demo state

## Run Locally

```bash
npm install
cp .env.example .env
npm run dev
